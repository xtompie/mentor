# Changelog

Every install has its version in `<skills dir>/mentor/VERSION`. To upgrade, see "Upgrading" in `INSTALL.md`.

## 0.1.0

- First release: `/mentor` turns a Claude Code session into one-line rules for the model or short lessons for the user, with evidence, an existing-rule check and approval per item.
- `session-text.pl` converts a session to compact text with core Perl only.
